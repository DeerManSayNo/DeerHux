# 弹窗与配置窗口

本模式覆盖从工作台打开的二级配置窗口、短确认、嵌套编辑窗口和需要阻断底层操作的业务模态。共享实现入口为 `components/ui/Modal.tsx`。

## 任务与布局

- 多对象配置使用 `split`：左侧导航选择真实对象，右侧编辑当前对象；两侧分别拥有滚动区域。
- 单一、短流程使用 `confirm`：标题、正文与固定操作区纵向排列。
- 标题说明当前对象或任务，副标题只承载路径、作用域等必要上下文，不写口号或重复说明。
- 窗口高度受当前视口约束。标题、导航和底部操作不被正文推出视口；超出内容在所属正文区域滚动。

## 层级与边界

- 外壳通过遮罩、表面和阴影建立模态层级，不叠加无职责的描边。
- 左右区域可通过不同表面区分。分组优先使用标题、间距、对齐和邻近关系；只在关系无法辨识时使用单条分隔线。
- 输入框、下拉框、文本域保留明确的可编辑边界。导航项、状态、添加入口和普通内容不默认加框。
- 禁止卡片套卡片、整页细灰线网格、虚线添加框、发光状态点、装饰性彩色图标块和大面积强调色选中态。
- 列表选中使用中性选中表面、文字或图标强调；强调色留给主操作、焦点和必要状态。

## 操作与状态

- 顶栏只放当前上下文、关闭和复制、导入、刷新等轻量工具。
- 创建、保存、应用、确认进入固定底栏，并且每个范围只有一个主操作。取消使用 `ghost`，破坏性操作使用 `danger`。
- 新增对象使用带加号图标的普通按钮，不使用整宽虚线占位框。
- loading、empty、error、success 与测试结果留在对应编辑上下文；状态提示只使用一种主要信号，不同时叠加边框、底色和图标容器。
- 异步忙碌期间阻止重复提交；不能关闭的阶段必须同时约束 Escape、遮罩点击和关闭按钮。

## 交互与适配

- 打开后聚焦首个可操作项，Tab 焦点保持在窗口内，关闭后恢复到触发控件。
- 遮罩点击和 Escape 默认关闭；进行中的不可取消任务除外。
- 所有导航项使用按钮或链接语义并支持键盘，纯图标按钮提供准确的 `aria-label`。
- 桌面保持紧凑信息密度；窄屏收紧边距和栏宽，关键操作持续可见，不允许弹窗超出主窗口。
