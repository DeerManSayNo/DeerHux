# 界面交互规范

## 定时任务会话

- 左侧不再展示独立的定时任务折叠栏。定时任务生成的会话与普通会话共用「最近」列表，按最后活动时间排序，沿用最近 5 条的展示规则及打开、重命名、删除行为。
- 内部 `scheduled-tasks` 与旧版 `wechat/remote-cwd` 目录的会话默认并入「默认」项目的历史列表，不生成独立项目，也不要求手动导入；普通项目目录中的任务会话仍归属原项目。会话的实际 cwd 与 JSONL 保持不变，历史会话可通过项目或搜索打开。主侧栏、快捷会话窗口与项目名称展示共用 `lib/project-name.ts` 的映射规则。
- 底部的定时任务管理入口负责配置与执行记录查看。
- 入口为 `components/SessionSidebar.tsx`，统一复用 `SessionItem`，不另行创建或复制会话。

## 左侧导航列表滚动条

- 桌面端采用 3px 圆角细线，使用 `text-dim` 的 55% 不透明度，轨道透明且不显示箭头；仅支持标准滚动条样式的浏览器回退到 `thin`。
- 项目与会话列表的滚动条默认透明，仅在鼠标悬停列表且发生滚动时显示；停止滚动 700ms 后淡出，鼠标移出时立即开始 180ms 淡出，再次悬停但未滚动时保持隐藏。
- 始终保留滚动条槽位，显隐不改变列表宽度；遵循系统减少动态效果偏好。入口为 `components/SessionSidebar.tsx`，样式为 `app/globals.css` 的 `.sidebar-navigation-scroll`。

## AI 回复中的链接

- 普通点击网页链接，Windows 桌面端使用系统浏览器，其他平台保留应用内预览；mailto/tel 使用系统处理程序。普通点击本地文件链接，打开文件预览。
- AI 回复中的空地址、非法地址和不支持的协议显示普通文本。本地文件链接须通过服务器的存在性、可读性与访问权限检查后才可点击，检查期间或失败时显示普通文本。Windows 盘符及 file:// 链接不得被 Markdown 默认清洗误删。网页仅校验协议与地址格式，不自动请求第三方网站或声称已验证可达性。
- Command/Ctrl + 点击网页链接，通过系统默认浏览器打开。点击处理必须阻止 WebView 的默认跳转。
- Command/Ctrl + 点击本地文件链接，通过系统默认应用打开（HTML 文件通常为浏览器）；必须先识别文件路径，避免被解析为应用路由而出现 404。
- 桌面端外部打开失败时显示错误提示，不回退到 WebView 跳转。统一点击处理在捕获阶段执行。
- 统一点击入口位于 `components/AppShell.tsx`，作用于 `[data-ai-output] a[href]`；外部打开复用 `lib/external-links.ts` 的 `openExternalLink()`，桌面端使用 Tauri shell，浏览器端打开新标签页。

Markdown 渲染入口为 `components/MessageView.tsx`，相关基础样式位于 `app/globals.css`。

- 代码块高亮主题的 `pre` 背景统一由 `backgroundColor: var(--bg)` 指定；合并第三方主题前移除其 `background` 简写，避免明暗主题切换时与长属性冲突。

## 模型配置保存

- 新增模型允许暂存未填写的草稿；点击保存时，缺少模型 ID（含纯空白）必须提示供应商与模型序号，并选中对应模型，供用户填写或删除。
- 后端使用运行时模型加载器校验候选配置，校验通过后才替换生效文件；失败返回具体错误，保留原配置和偏好设置。
- 界面入口为 `components/ModelsConfig.tsx`，共享草稿校验为 `lib/models-config-validation.ts`，保存接口为 `app/api/models-config/route.ts`。

## 工具调用活动行

- 当前未结束的工具段只在聊天流底部、输入框上方的状态区展示，替代该位置的普通阶段文案；执行、等待模型继续及恢复状态共用此行，诊断信息仍在下方。消息正文里不重复展示实时工具行，Token 用量保留在所属消息下方。正文开始后原工具段转为消息中的历史分类摘要，回合结束时底部活动行消失；展开状态随同一分组迁移保留。

- 每条工具活动行及历史分类摘要的文字后显示 14px 折叠箭头：收起朝右、展开朝下；执行中的转圈独立展示，不替代箭头。调用次数和状态仍右对齐。

- 工具活动行、历史分类摘要及整轮过程与后续正文之间不绘制横向分隔线，使用现有留白区分内容。展开历史过程后，过程正文中的 Markdown 横线连同占位隐藏。历史内容间隔为 4px，工具行上下内边距各 2px，工具组不额外添加底部留白；空白正文块不占位。

- 当前回合的连续工具调用跨 assistant 消息合并成一个固定 24px 高的活动行；新调用到来时用 180ms 向上滚动切换文本，不再堆叠最近五个工具卡片。显示最新执行中的工具及文件路径或命令，长内容单行省略，悬停可查看完整行摘要；遵循减少动态效果偏好。
- 收到非空正文后，之前的工具段收为分类摘要；正文之后的新工具开启新的活动行。工具返回文本、空白正文和思考不触发分段；流式与落盘重叠时按调用 ID 去重，分组和展开状态保持稳定。
- 历史摘要按工具类别去重：只有 bash 显示「运行了命令」，read + bash 显示「已读取文件并运行了命令」；其他类别包括查看目录、查找文件、搜索内容、查询代码关系、修改文件、写入文件和调用其他工具。按声明的工具类型分类，不猜测 shell 命令实际读写了哪些文件。
- 点击活动行或摘要可展开每次调用，继续点击工具查看参数和结果。活动行显示调用总数、正在执行数和失败数；只以真实活动 ID 判断执行中，已返回结果的不再计入。等待执行与失败明确显示，分类摘要不表示全部成功。
- 完成后的整轮过程入口也使用分类摘要并附耗时；展开后保留过程正文与按段归类的工具记录。没有最终正文、停止或异常结束也收起工具列表，错误提示继续可见。历史思考保持隐藏。
- 用户在底部时跟随输出；暂停追底时不主动恢复。向上滚动后保留「回到底部」按钮。分组与分类位于 `lib/streaming-tool-layout.ts`，接入位于 `components/ChatWindow.tsx`，展示与样式为 `components/MessageView.tsx`、`components/tool-activity.css`。

## 对话框添加文件

- 粘贴、拖拽和左下角「上传文件」按钮采用相同规则：图片进入现有图片附件链路，展示图片预览并随消息发送；非图片文件保留原始路径，展示右侧引用胶囊，不复制到项目。
- 桌面端文件选择器支持任意类型、多选；剪贴板和原生拖拽提供原始路径。应用内文件列表拖拽提供路径载荷；重复非图片路径去重。
- 网页端有图片内容时直接作为图片附件；非图片无法取得原始路径时提示使用桌面端或应用内拖拽，不根据文件名猜测路径。
- 桌面端读取剪贴板原始路径失败时，仍使用剪贴板中已有的图片内容添加附件；混合粘贴中无法取得路径的非图片文件继续显示路径提示。
- 图片通过 `/api/chat-image-upload` 保存至现有聊天图片目录，支持图片内容和原始图片路径两种入口；取消选择不改动输入。
- 入口为 `components/ChatInput.tsx`、`hooks/useDragDrop.ts`、`components/FileExplorer.tsx`；剪贴板路径解析为 `lib/clipboard-file-paths.ts`，桌面读取命令为 `read_clipboard_file_paths`。
- 图片添加后立即显示附件卡片；粘贴有本地预览时先显示缩略图，只有原路径时先显示同尺寸占位。两者均在保存期间显示相同转圈并暂停发送，成功后替换为就绪预览；失败移除卡片并提示，处理中移除的卡片不会在完成后重新出现。

- 拖拽遮罩以每个 session 的聊天窗口为范围：覆盖该窗口的消息区、空白区和输入区，不覆盖应用侧边栏及其他聊天窗口。落在哪个 session 就添加到哪个 session，不依赖原先焦点。拖出该窗口或结束拖拽后收起遮罩；桌面原生事件按实际落点命中对应聊天窗口。

- 原生拖拽坐标按平台转换：当前 Wry 0.55.1 在 macOS 返回逻辑点，不能再直接除以 Retina 像素比；其他平台按物理像素转换。统一由 `lib/native-drag-position.ts` 处理，悬停遮罩和松开落点共用同一转换，并计入 WebView 缩放。

## 全选范围

- 输入框和可编辑区域保留原生 Command/Ctrl+A，仅选择编辑内容。
- 聊天区的 Command/Ctrl+A 限定在该 session 的消息区域，不跨到其他 session、侧边栏或输入工具栏；有消息选区时优先沿用其所属 session。
- 聊天消息保持可拖选复制，按钮、会话列表项和输入工具栏不参与普通文本选择。入口为 `hooks/useChatSelectAll.ts`，由 `components/ChatWindow.tsx` 接入。

- 消息区仅用户正文、AI 正文及代码内容可选；时间、模型名、系统提示词入口、处理状态、代码语言标签、行号和复制按钮不显示选区。复制选区时同样过滤这些元信息，保留正文段落与代码换行。正文使用 `data-message-body` 标记，代码工具栏使用 `data-selection-ignore`。

- 代码块的选中背景仅覆盖代码行的实际文字宽度，不覆盖容器内边距和行尾剩余宽度；保留源代码的缩进与真实空行，不以裁剪代码内容实现视觉效果。


## 分享窗口

- 视觉入口为 `components/sharing/sharing.module.css`；图标、品牌、复制字段、错误提示和到期时间格式复用 `components/sharing/ShareUI.tsx`。样式限定在分享组件内，复用全局明暗主题和蓝色强调色，不修改原生聊天布局。
- 主人入口为 AppShell 左上角设置菜单的「分享窗口」，位于「扩展总览」之前；使用统一菜单项样式，点击关闭菜单并打开分享弹窗，左侧不再展示独立卡片。ShareManager 使用原生 dialog，支持焦点约束、Escape 关闭和关闭后焦点恢复；分为「创建分享」与「正在分享」两个页签。
- 分享项目候选直接复用 SessionSidebar 经 AppShell 传入的完整项目列表，共用默认目录归并、子 Agent 排除、隐藏、手动引入和置顶排序规则；不受侧栏搜索或前 5 项展示限制影响。项目名称沿用侧栏名称，搜索匹配名称与路径；候选中已移除的项目不计入选择，也不提交分享。
- 创建页采用资源表单与分享摘要两栏：项目支持名称与路径搜索，以名称和路径展示，模型双列选择，角色以紧凑选项展示，读写权限以明确的两张卡片选择；默认只读。摘要持续显示资源数量、权限和有效期；有效期提供 1、8、24 小时、永久和自定义时长。永久在管理页和访客顶部显示「永久有效」，并说明应用重启或手动停止后仍会失效。窄屏改为单列。
- 创建成功后展示独立结果页：链接、6 位匹配码、一键复制和复制结果反馈。复制不可用时选中文本并提示手动复制。管理页使用分享卡片，展示权限、到期时间、链接、6 位匹配码及各自的复制按钮。旧版未保留原码时，明确提示并提供生成新码入口，操作前说明旧码失效、已登录访客不受影响。
- SharedWorkspace Web 页采用克制的文档工作台风格，移除宣传口号、功能卖点与渐变。登录页采用单列居中表单。匹配码保留单个真实输入框，数字键盘提示、6 位校验、前导零、粘贴及自动填充均可使用；提交直接读取实际输入值，不根据可能滞后的 React 状态禁用按钮。
- 客户端初始化前显示「页面加载中…」，认证期间显示「验证中…」；错误信息出现在输入与提交按钮之间，失效分享切换为明确的结束状态。登录前不展示授权资源和主人项目信息。
- 访客工作台使用简洁顶部栏；资源与窗口侧栏默认收起，通过顶部按钮展开。单窗口使用完整内容区，多窗口以细分隔线区分。已选资源只作用于新窗口；窗口最多 12 个，最多并排展示 3 个。收起操作不删除会话，选中状态有文字提示与 aria-pressed 语义。
- 空工作台引导创建第一个窗口；空聊天展示权限说明。聊天复用 ChatInput 和 MessageView，textOnly 禁用附件、本机角色/技能发现及扩展菜单。保留输出中和完成后的「回到底部」胶囊。
- 明暗切换复用 useTheme，保持代码高亮与主题一致。手机端资源区按需侧滑展开，聊天单屏宽度；支持键盘焦点提示和减少动画偏好。
- 产品文案必须注明主人设备在线、当前进程有效及 HTTPS 公网 / HTTP 局域网边界；业务权限始终由服务端校验，样式不得引入权限扩展。

### 分享 Web 阅读列

- 历史消息、用户消息、实时输出与工具结果统一位于 readingColumn；输入框和错误提示复用相同宽度的 composerInner。最大宽度 800px，左右自动留白，正文左对齐。侧栏收起时相对于页面居中，展开时相对于主内容区居中；并排窗口各自居中。
- 阅读列内边距为 28px，聊天容器小于 560px 时缩为 18px。对称预留滚动条空间，防止滚动条出现时中心轴偏移。正文 15px / 1.85 行高，窄列 14px。长代码与表格在自身内部横向滚动，不撑宽布局。
- 输入框位于消息视口下方，高度自适应。「回到底部」定位于消息视口内底部，不再依赖固定输入框高度。内容尺寸改变时仅在跟随状态滚动，向上阅读后保持暂停。
- 分享页通过 ChatInput 的 fitContainer 属性取消组件自身的宽度上限与横向内边距，由父级阅读列统一约束；其他调用保持默认尺寸。
- 单窗口不加外层卡片，多窗口最小宽度 440px；手机每个窗口占满内容区，通过横向滚动切换。空状态直接显示项目、权限与下一步操作，避免装饰性图标与口号。
- 改动限定于 webSurface 与分享 CSS module，不改变主人端弹窗及原生消息组件的默认外观。

## 窗口接入微信

- 微信会话绑定统一从聊天窗口入口操作；主侧栏不再展示「远程连接」区块。扫码登录与账号管理保留在微信设置中。

- 多窗口的「接入微信」使用双气泡图标，位于窗口标题栏右侧、资源管理器按钮之前，不再占用正文独立一行；单窗口入口位于内容顶部右侧。图标悬停提示和无障碍名称展示连接状态，已绑定窗口附带状态圆点。
- 每个聊天窗口提供「接入微信」入口；直接绑定同一个 Session，共用当前项目、角色、模型和历史上下文。空窗口先创建会话再绑定，不发送占位消息；已创建但尚无消息且未运行的会话继续显示项目标题、欢迎语和居中输入框，已创建会话的项目不可切换；创建完成保持空闲，只有真实消息发起执行后才显示「正在思考」和停止按钮。
- 只有一个已知微信端时点击直接接入；多个端时显示当前会话供选择。「微信已接入」可查看并解除绑定；同一个端切换窗口后仅后续消息进入新窗口，不搬移旧消息。
- 弹窗复用主题变量与原生 dialog 的焦点约束、Escape 关闭及焦点恢复。未登录或尚无微信端时提供微信设置和首条消息引导；绑定后自动启动监听；只有已登录且监听中才显示「微信已接入」，停止、登录失效和收信异常分别提示。
- 微信端处理中禁止切换和解除；窗口已有回合运行时微信消息等待其结束，再执行新回合。主人设备与 DeerHux 需在线。入口为 `components/WindowWeChatButton.tsx`，样式为 `components/window-wechat.module.css`。

- 已连接窗口支持双向文字同步：电脑端发送成功后，微信收到带「电脑端」标记的用户消息，回合完成后收到带「AI 回复」标记的最终正文。思考、工具调用和逐字更新不推送，图片仅显示文字占位；已有历史不自动回灌。微信发起的回合沿用原回复链路，不回显输入或重复推送答案。
- 同步由 `lib/wechat-session-mirror.ts` 订阅服务端会话事件实现；同一微信端顺序发送，解除绑定、切换窗口或停止监听后取消未发送的旧窗口同步。

- 微信「正在输入」在收到消息开始处理时启动，覆盖会话恢复、排队、模型和工具执行，回复发送完成或失败后结束；电脑端发起的已绑定会话同样显示。长回合每 15 秒续期，同一微信端有多个等待任务时保留状态，最后一个任务完成才关闭。状态接口失败不阻塞回复，停止监听、解除绑定时清理状态。

## 历史消息编辑

- 每次打开历史消息编辑框后，发送按钮禁用 3 秒，颜色保持正常状态，发送处理函数同时校验时间，避免双击或连续回车误发送；期间允许输入、选区与取消，关闭时清理计时器，再次打开重新计时。

- 系统提示词弹窗底部展示“本轮 Skill 记录”，按用户选择、上下文注入、工具读取、入口调用分组显示去重胶囊；悬停查看证据路径。注入成功与否随 turn_context 持久化，历史未记录时明确提示，不用选择记录代替注入证据。工具记录仅取当前用户消息至下一条用户消息之间的成功操作；支持显式读取和简单脚本命令归属，不把回答提及、搜索结果或复杂命令字符串当作调用。

- 主输入框、历史用户消息展示气泡与编辑框通过 `useTheme` 同步背景颜色：深色模式为 `rgb(42, 42, 42)`，浅色模式为白色。

- 最新可见消息的信息行默认显示（用户为发送时间，已完成 AI 回复为底部模型、消耗、耗时及时间）；有新消息后旧消息恢复悬停显示。

- 正在执行回合内的所有 AI 消息（含最新流式输出、工具执行和等待模型阶段）不展示或预留模型名、Token 用量、耗时及时间统计栏，悬停也不显示，工具摘要后仅保留消息底部的 8px 间距。回合结束后恢复统计栏；已完成的历史回合与工具运行状态沿用原有展示行为。

- 消息间距保持紧凑：用户气泡底部 12px，AI 回复底部 8px；连续两条可见用户消息之间额外预留 12px，避免下一条上方时间与前一条气泡重叠；用户时间悬浮在气泡上方，不单独占一行；消息列表内层预留 18px 顶部空间，避免首条时间被溢出裁切。回复下方统计区固定单行 22px，窄窗口可横向滚动，不因隐藏统计折行而增加空白。

- AI 模型名称与 Token 消耗、总耗时、时间统一放在回复下方，不占用正文上方空间；消息时间、模型名称、Token 消耗和总耗时默认隐藏并保留布局空间，仅悬停对应消息内容或键盘聚焦时显示；每条消息独立控制，AI 信息显现后可移入统计操作区复制。

- 系统提示词入口为消息框左侧的齿轮图标，不显示文字胶囊；仅文本气泡悬停或键盘焦点进入时显现，移到图标上保持显示，预留位置避免布局跳动，点击继续打开提示词弹窗。

- 用户已发送消息靠聊天区域右侧显示，气泡按内容收缩，最大宽度为消息容器的 85%；正文保持左对齐，长文本自动换行。编辑时恢复完整可用宽度，AI 回复布局不变。

- 历史消息展示框、编辑框及底部主输入框均不显示边框，仅使用柔和阴影区分区域（常规阴影为 `0 2px 4px rgba(15,23,42,0.07), 0 8px 24px -12px rgba(15,23,42,0.16)`）；消息悬停时增强阴影，不使用描边式阴影。

- 历史编辑区与主输入框共用 `components/SendIconButton.tsx`：30px 圆形按钮、向上箭头，无可见文字；空内容时禁用。历史编辑区不展示取消按钮，点击编辑框外部或按 Escape 取消并恢复原文。

- 用户消息编辑与重新发送不依赖持久化 entry ID，停止后尚在同步的消息也可编辑。消息气泡使用可聚焦容器，正文可拖选复制；松开已有选区时不进入编辑，普通点击或焦点位于气泡时按 Enter/空格进入编辑。编辑不绕过停止收尾期间的发送限制。

- 技能支持在同一条消息中多选：输入 `/` 或在正文空白处输入 `/` 搜索并追加，已选技能不重复添加、不清空正文。技能标签在文本区上方自动换行，可逐项移除，光标位于正文开头时退格逐个移除末尾技能。草稿、发送、排队、重发和历史恢复保留完整选择，后端按选择顺序加载每个技能的指令；兼容旧单技能记录。
- 主输入框与历史消息编辑框随内容自动增高和缩回，不设置 200px 高度上限、不产生内部滚动条；恢复草稿和窗口宽度变化后的自动换行也重新计算高度。
- 主输入框采用一个完整圆角容器：上方为文本区，底部同一行放附件、角色、模型、Subagent、更多及发送／停止按钮，发送操作位于最右侧。窄窗口下角色和模型名称收缩省略，底部控件不产生横向溢出。
- 底部工具栏以 32px 高度垂直居中，发送按钮为 30px 圆形，停止及其他操作保持 32px，图标视觉中心处于同一水平线。
- 粘贴路径解析或图片上传期间暂停发送，但发送按钮配色只随输入内容是否为空变化，不因短暂禁用反复变灰闪烁；处理中通过提示和忙碌状态表达。
- 工具栏按钮区域距输入框内侧左边缘 6px、下边缘 4px；文本区保留原有阅读内边距。
- 更多按钮使用几何居中的三点 SVG，不用基线偏下的文本省略号；角色和模型选择统一 16px 文字行高、无上下内边距，按内容中心对齐。

- 历史消息编辑框使用原生文本选区，拖动选择及 Command/Ctrl+A 全选显示系统高亮；聊天区隐藏非正文选区的规则必须排除输入控件和可编辑区域。

- 历史消息编辑输入框使用块级布局，单行高度 30px（24px 行高、上下各 3px 内边距），与 30px 发送按钮垂直居中；多行随内容自动增高，发送按钮保持底部对齐，不保留行内基线空隙。

## 主动停止回复

- 用户点击输入框停止按钮后正常结束本轮，不展示模型调用失败或中止错误提示。已有输出保留并写入会话；未产生内容时不显示空助手回复、模型名和耗时占位。真实调用失败、超时和意外中断继续显示错误。

## 右侧资源管理器与预览

- 多窗口内的输入工具栏按窗口实际可用宽度收缩，角色和模型名称超出时省略，上传和更多操作保持可见，不能撑出窗口级横向滚动条。

- 左侧导航仅展示项目与会话，移除底部资源管理器及上下分隔拖拽。资源管理器迁入右侧扩展栏，与「预览」共享空间，通过顶部按钮切换。
- 资源管理器显示当前聚焦聊天窗口的项目，顶部显示项目名（悬停查看路径）与刷新入口。没有项目时显示选择项目提示。文件树复用 FileExplorer，保留打开文件、拖拽和添加引用能力。
- 未固定右栏时，点击文件切换到预览，保留多文件标签与网页预览；关闭最后一个预览标签回到资源管理器。文件预览弹出独立窗口后，资源管理器仍可使用；预览页提供收回入口。
- 按项目路径持久保存展开目录、选中文件和滚动位置，不设置过期时间；切换项目、收起再打开或重启后恢复各项目自己的层级。收起父目录保留子目录的展开记录，再次展开父目录时恢复。复用 `lib/file-explorer-state.ts` 与快捷会话弹层共用存储；项目状态读取完成后再挂载对应文件树，初始化和恢复不回写展开状态，用户展开、收起或选中文件时立即保存。
- 资源管理器默认宽度 320px，最小宽度 200px；预览默认 500px，最小宽度 250px，分别记住拖拽宽度。窗口宽度不超过 1000px 时，右栏覆盖于内容之上，通过顶部应用工具栏收起右栏；收起后不参与键盘导航。
- 主工作区多窗口标题中的文件按钮打开右侧资源管理器，并聚焦对应窗口。快捷会话抽屉保留原文件弹层。
- 编排位于 `components/AppShell.tsx`，项目文件区为 `components/WorkspaceExplorer.tsx`，视觉样式为 `components/workspace-panel.css`，复用全局主题变量。

- 右栏右上角使用图钉固定当前视图，替代关闭按钮。固定状态以强调色和 aria-pressed 表达，并记住用户选择；固定后打开 Markdown、其他文件或网页仍添加预览标签，但不自动切换视图或展开右栏。用户仍可手动切换资源管理器／预览，或通过应用顶部按钮收起右栏。取消固定后恢复打开文件自动进入预览。

## 左上角应用工具栏

- 新建会话、设置、主题切换紧邻左上角侧栏展开／收起按钮，后接右侧扩展栏开关；侧栏收起时仍可操作。保持与窗口控制按钮的原有间距。
- 删除聊天区浮动工具栏、悬停展开箭头和自动收起逻辑。聊天区域保持原有顶部布局，不为左上角工具按钮增加整行留白。
- 设置菜单从左上角按钮下方展开，保持点击外部和 Escape 关闭行为。工具按钮沿用主题、图标和功能，不再绘制浮动胶囊背景。

- 左上角五个按钮统一使用 28px 点击区、15px 图标画布与 1.25px 等粗圆角线条；图形主体约占 18/24，调整加号、齿轮和太阳的占比，保持视觉大小和中心一致。规则限定在 `.app-header-actions` 内。

- 工具栏图标中心与红绿灯中心水平对齐；macOS 工具栏 28px 点击区从 top=2px 开始，中心为 y=16；其他桌面平台自绘红绿灯中心为 y=20，对应工具栏 top=6px。macOS 原生红绿灯直接按窗口坐标定位，三个中心为 (16, 16)、(39, 16)、(62, 16) pt；不再使用 Wry 的标题栏内边距定位。窗口创建和原生控件同步时校正，系统全屏标题栏除外，其他桌面平台自绘红绿灯 top=14px。设置菜单从 top=39px 展开，仅左侧导航头部预留 33px，不给聊天区添加顶部白栏。

- macOS 工具栏从 left=82px 开始，首个图标与绿色窗口按钮的中心距约 34px，与工具按钮之间 28px 点击区加 2px 间隔的节奏一致。自绘红绿灯平台沿用 left=76px，以适配其 20px 圆点中心距。设置菜单随按钮横向位置对齐。

- 工具栏两端的侧栏图标互为水平镜像：左侧按钮窄栏在左，右侧按钮窄栏在右，窄栏以淡色填充强化方向。展开／收起状态均保持图标方向，不切换为汉堡菜单；右侧预览独立窗口状态也沿用右栏图标。

- 左上角红绿灯与五个全局按钮在侧边栏展开时常驻显示；仅侧边栏收起时自动隐藏，鼠标位于左上角 246 × 48px 区域时显示，工具栏淡入、淡出均使用 450ms ease-in-out。键盘焦点或设置菜单打开时保持显示，触屏保留工具栏；macOS 原生红绿灯与工具栏共用原生区域检测，均使用 450ms ease-in-out 透明度动画；仅目标状态变化时启动动画，不改变布局占位。
- 正式包通过本机 HTTP 页面调用原生控件命令；`sync_header_controls` 必须在应用命令清单中注册，并由 `main-header` capability 授权给主窗口的本机来源。同步失败需记录错误，不能仅凭前端按钮隐藏判断原生红绿灯已隐藏。

- 展开侧栏时，搜索区域底部与项目列表顶部均不额外留白，缩短搜索到项目标题的距离；分组标题自身内边距保持统一。

- 单窗口与多窗口欢迎页的项目标题统一距内容区顶部 12px（紧凑模式 8px），不再保留旧顶部操作区的 50px 空白。

## 已修改文件列表

- 「n 个文件被修改」下方文件行复用聊天区文件右键菜单，提供复制相对路径、复制绝对路径、打开所在文件夹（macOS 显示「在 Finder 中显示」）和使用默认应用打开。相对路径以所属会话项目目录为基准，项目外文件沿用完整路径。
- 普通点击文件行时打开右侧资源管理器（已打开则保持打开），切换到所属项目、展开祖先目录、滚动定位并高亮文件；重复点击仍会重新定位。项目外文件以所在目录为资源根，无法定位时显示原因。定位刷新目标目录以包含刚新增的文件，并保留原有展开状态；显式定位优先于历史滚动位置恢复。
- Command/Ctrl + 点击使用默认应用打开；右键菜单沿用主题、视口边界定位、键盘导航和操作失败提示。入口为 `components/ChangedFilesList.tsx`，通过 `data-file-menu-path` 接入 `components/AiFileLinkMenu.tsx`。定位经 `ChatWorkspace`、`AppShell` 传入 `WorkspaceExplorer` 与 `FileExplorer`，文件树内点击仍打开预览。

## 思考过程展示

- 仅展示正在流式生成的当前思考块；同条消息中更早的思考块、已完成消息和历史回合中的思考全部隐藏，展开历史过程也不重新展示。
- 开始输出正文、调用工具或结束回复后隐藏思考卡片；只包含历史思考的消息不留下空的模型名和消息占位。正文、工具记录、错误提示及会话持久化内容保持原有语义。入口为 `components/MessageView.tsx`。
